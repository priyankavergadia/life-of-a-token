# Project: MCP (Model Context Protocol) — For Everyone (no coding needed)

How **MCP (Model Context Protocol)** acts as the universal **USB-C port for AI** —
letting any AI app plug into databases, policies, and tools without custom wiring.

👉 **Open it:** https://priyankavergadia.github.io/life-of-a-token/#/mcp

---

## Before you start
Add a free API key in the **⚡ Go live** bar (any provider works here). No key →
demo mode.

---

## Walk it
1. **Overview** — Read the pipeline: Host / Client ⇄ MCP Protocol ⇄ MCP Servers ⇄
   Databases & APIs.
2. **The USB-C Port** — Toggle between **🔌 With MCP** and **🍝 Before MCP**, and
   see the 3 building blocks every MCP server can share:
   - **📄 Resources** (facts to read — like *RAG* & *Context*)
   - **🔧 Tools** (actions to take — like *Tools & Agents*)
   - **💬 Prompts** (reusable templates — like *Vibe Coding*)
3. **Live Handshake** — Click the server buttons (**📦 orders-mcp**, **📜 policy-mcp**,
   **💬 slack-mcp**) to plug or unplug them, then click **🔌 Discover & run via MCP
   for real**. *Lesson: the AI discovers whichever tools and policies are plugged in
   at runtime and chains them automatically.*

## ✅ What you'll understand
Why the industry standardized on MCP: instead of writing custom glue code for every
AI app and every company database, you build an MCP server once and plug it in
anywhere.
